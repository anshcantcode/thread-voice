# Project provenance

THREAD Voice was started on 20 October 2026 as an independently implemented, locally runnable successor to [anshcantcode/thread-team-guide](https://github.com/anshcantcode/thread-team-guide), a Samsung PRISM hackathon project built by the ReflexAi team. The earlier prototype established the product interest in interruptible voice interaction. Its team contributions remain credited in that repository and history.

This repository starts a new runtime history and scope. The Python runtime, Gemini protocol adapter, web integration, synthetic audio checks, tests, and documentation were created for this successor. In v0.1.1, at the owner's request, the original THREAD frontend was restored: its base styles, acoustic-blue theme, workspace styling, living orb renderer, sphere image and bundled fonts come from predecessor commit `2ec4eccf3dd2b5568814fc2033c4bc353008bff2`. The restored layout is connected to this repository's runtime and supported controls. See THIRD_PARTY_NOTICES.md for exact paths and font licenses.

The predecessor's models, voice clips, benchmark datasets, slide decks and reports are not bundled. Its historical scores do not apply to this implementation. Restoring the frontend preserves that team's design work; it does not claim the inherited design as newly authored here.

Ansh owns and maintains this repository. Being the sole maintainer describes current repository access; it does not imply sole authorship of the earlier team project. AI coding assistance was used to implement and check this release. The software and its measured limitations should be reviewed on their own evidence.
