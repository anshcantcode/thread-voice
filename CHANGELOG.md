# Changelog

## 0.1.1 — 20 October 2026

Restored the original THREAD frontend: acoustic-blue WebGL orb with image fallback, original typography, full-screen conversation layout, compact voice dock, and dark workspace. Moved runtime diagnostics into the task-record inspector. Connected the restored layout to current search, note confirmation, notebook, transcript, export and interruption controls; added microphone mute and a working sensitivity control. Bundled fonts, font licenses and frontend provenance in the installable wheel.

## 0.1.0 — 20 October 2026

Initial independent developer release: session-owned revision fencing and cancellation; proposal-bound confirmation; idempotent local note persistence and notebook reading; a keyless interruption scenario; an event timeline and JSON export; an optional Gemini Live relay; owned browser audio playback and microphone cleanup; Python packaging, Docker configuration and Windows/Linux verification.

Live provider and physical acoustic qualification remain pending. See [verification](docs/VERIFICATION.md) and [provenance](ORIGINS.md).
